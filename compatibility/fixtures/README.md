# Compatibility fixtures

This directory holds .sdltm files generated by `biconvert` for manual
verification against real Trados Studio installs. **Do NOT commit the
.sdltm binaries themselves to git** — they're trivially regenerable and
bloat the repo. Only commit:

- This README
- Any screenshots / logs that document a specific failure mode

## How to generate the fixtures

From the repo root:

```bash
# basic
biconvert tests/fixtures/docx/basic.docx -o compatibility/fixtures/basic \
    --src en-US --tgt zh-CN

# special_chars (hand-built — uses the same strings as the
# test_sdltm_unesc_handles_literal_ampersand_sequences_correctly test)
python -c "
from language_tools import api
from language_tools.model import TranslationUnit
units = [
    TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                   src_text='The spec says R&D output &lt; 5% error, use < and >.',
                   tgt_text='规格。'),
    TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                   src_text='Sales grew, e.g. in Q3 <they> doubled & tripled.',
                   tgt_text='销售额增长了，例如第三季度<翻倍>并且&三倍。'),
]
import os
os.makedirs('compatibility/fixtures', exist_ok=True)
from language_tools.writers import sdltm_writer
sdltm_writer.write('compatibility/fixtures/special_chars.sdltm',
                   units, 'en-US', 'zh-CN', 'special-chars')
print('wrote', len(units), 'TUs')
"

# numbering_mismatch
biconvert tests/fixtures/docx/numbering_mismatch.docx \
    -o compatibility/fixtures/numbering_mismatch \
    --src en-US --tgt zh-CN

# large (concatenated: repeat basic 250 times → ~1000 TUs)
python -c "
from language_tools import api
from language_tools.model import TranslationUnit
import os
os.makedirs('compatibility/fixtures', exist_ok=True)
from language_tools.writers import sdltm_writer
base = [TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                        src_text='Dr. Smith arrived at 9 a.m. and started the meeting.',
                        tgt_text='史密斯博士上午9点到达，开始了会议.'),
       TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                       src_text='The new AI system improved accuracy significantly.',
                       tgt_text='新的人工智能系统显著提高了准确性。'),
       TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                       src_text='It also reduced costs.',
                       tgt_text='它还降低了成本。'),
       TranslationUnit(src_lang='en-US', tgt_lang='zh-CN',
                       src_text='Apple Inc. released the report in Jan. 2024.',
                       tgt_text='苹果公司于2024年1月发布了报告！')]
units = base * 250
sdltm_writer.write('compatibility/fixtures/large.sdltm',
                   units, 'en-US', 'zh-CN', 'large-fixture')
print('wrote', len(units), 'TUs')
"

# reversed
biconvert tests/fixtures/docx/reversed_direction.docx \
    -o compatibility/fixtures/reversed \
    --src zh-CN --tgt en-US
```

Then copy the resulting `*.sdltm` files to a Windows machine with Trados
Studio installed and walk the four-step checklist in
`compatibility/studio-readable.md`.

## Why these fixtures?

See the "Test matrix" section of `compatibility/studio-readable.md` —
each fixture exercises a distinct code path in `sdltm_writer.py`:

- `basic` — smoke (plain ASCII + CJK)
- `special_chars` — `esc()` correctness (literal `<`/`>`/`&`, `&lt;` substring)
- `numbering_mismatch` — non-trivial alignment output
- `large` — first-open "updating indexes" progress dialog
- `reversed` — zh→en direction (language code wiring in `translation_memories` row)
